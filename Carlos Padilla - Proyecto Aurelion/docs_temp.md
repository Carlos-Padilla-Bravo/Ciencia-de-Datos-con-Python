# Documentación Interactiva - Proyecto Aurelion

Este programa ha sido actualizado para incluir todas las secciones de la documentación del Proyecto Aurelion, incluyendo las nuevas secciones de requisitos técnicos y validaciones.

## Características actuales

- Navegación interactiva por todas las secciones del documento
- Visualización paginada para contenido extenso
- Manejo especial para diagrama de flujo y pseudocódigo
- Interfaz de usuario limpia y fácil de usar
