# Ciencia de Datos con Python
Contiene documentación y archivos relacionados con Proyecto de Tienda Aurelion, desarrolado en el marco de curso de IBM en conjunto con Guayerd de Argentina.
El repositorio contiene:
- Documentación completa del proyecto
- EDA (Exploratory Data Analysis)
- Visualización de Datos
- Análisis Predictivo y de Clasificación
